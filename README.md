# Campus Lost & Found

A web-based Campus Lost & Found system that helps students post and track lost and found items within their campus.

## 📌 About the Project

The Campus Lost & Found application provides a simple platform where users can share information about lost or found items and help connect items with their owners.

## ✨ Features

- 📦 Post lost and found items
- 🔎 Track lost/found item information
- 🏫 Campus-focused lost and found system
- 🌐 Web-based interface
- 💾 MySQL database integration
- 📱 Bootstrap-based user interface

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap
